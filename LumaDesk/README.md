# LumaDesk Laravel Landing Page

A static business landing page created for a Laravel web development activity.

## Business
LumaDesk — Modern Study & Productivity Space

Tagline: "Focus Better. Create More."

## Included
- Laravel Blade view
- Laravel route
- Responsive HTML structure
- CSS Flexbox and Grid
- CSS animations and transitions
- Mobile navigation
- Scroll reveal animation
- Front-end contact form validation
- Interactive space selection
- Accessibility basics
- No database, authentication, API, or dynamic backend required

## Files
resources/views/welcome.blade.php
public/css/style.css
public/js/script.js
routes/web.php

## Installation

1. Create/open your Laravel project.
2. Copy these files into the matching folders.
3. Make sure `routes/web.php` contains the supplied route.
4. Run:

php artisan serve

5. Open the local URL shown by Laravel, usually:
http://127.0.0.1:8000

## Important
This project intentionally uses only static/front-end functionality, as required by the activity. The contact form does not send data to a database or server.
